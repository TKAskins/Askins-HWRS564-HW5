From HYDRUS simulation to cost-optimal soil sensor selection using decision tree regression

1D Richards equation solved over the flood event; free drainage at the lower boundary
Outputs recorded at each node at every print time: water content θ, matric potential h, and flux q

1,600 candidate input features per trial — 2 sensor types × 50 depths × 16 time steps
Trials split 80 / 20 into training and test sets (random seed fixed for reproducibility)

Training Cost-Aware Decision Tree Regression dt_cost_by_level_main.py

Cost threshold swept from 0.0 (accuracy only) to 1.0 (cost only) in 11 steps; one tree trained per value

Figure. Overview of the decision tree sensor optimisation pipeline. HYDRUS 1D simulations generate synthetic soil water data across the full space of soil textures, root depths, and plant types. A cost-aware decision tree is then trained on 1,600 candidate sensor features, sweeping a cost threshold parameter to trace the trade-off between sensor network cost and predictive accuracy. The trained trees are evaluated on held-out test data, and the resulting cost–accuracy tables identify the sensor configuration — type and depth — that best satisfies the monitoring objective at each level of cost constraint.
